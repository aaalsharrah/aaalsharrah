# Abdallah Alsharrah

**Founder & CEO of [DetentLabs](https://detentlabs.ai), building [SafeClick](https://safeclick.dev).**

SafeClick is a security decision layer between authorization and irreversible execution. My work focuses on verifying intent before transactions are signed.

I work across full-stack engineering, blockchain security and cryptographic architecture. I graduated from **Hofstra University with a B.S. in Computer Science (Web & Mobile Engineering), Spring 2026** and founded the Hofstra Quantum Computing Club (HQCC).

## Current work

- **SafeClick:** security for Web3 transactions, including malicious contracts, phishing and wallet-draining threats.
- **Agent payments:** pre-sign enforcement with deterministic ALLOW, HOLD and BLOCK decisions. Only verified ALLOW may approach the signer.
- **Security engineering:** context-bound authorization, signer boundaries, replay protection and adversarial testing.
- **Full-stack infrastructure:** APIs, evidence services and interfaces for security integrations.

Agent payment enforcement is a separate product track from human-wallet security. Capabilities and integration maturity are documented per repository; tests and simulations are not claims of production or live settlement.
